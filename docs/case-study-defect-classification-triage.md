# Enterprise Defect Classification and Triage — Clearer Ownership and Follow-Up

## Business challenge
In enterprise UAT, reported failures can originate from different causes. Without consistent classification, teams may spend time routing issues to the wrong owners or treating test-data and training issues as implementation defects.

## My role
Supported defect governance, tracking, triage, ageing, escalation and retest/closure coordination within a multi-workstream SAP S/4HANA Finance testing programme.

## Solution
Created a custom Jira dropdown field named **Defect Classification** with seven selectable categories:

1. Partner system
2. Training
3. Test Data
4. Implementation
5. New requirement
6. New minor requirement
7. Migration

Used classification as a structured input for defect discussion, assignment and follow-up alongside defect status, severity, ageing and retest progress.

## Programme context
Worked within an environment tracking **1,500+ defects** across enterprise testing activities. This figure describes programme scale, not a count of defects individually resolved by the portfolio owner.

## Business value
A consistent classification vocabulary supported clearer triage conversations, better routing and more transparent reporting on outstanding issues.

Jira · Custom fields · Jira/Xray · JQL · Defect dashboards · Stakeholder reporting
