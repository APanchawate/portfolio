# UAT Setup Automation — Faster, Repeatable Enterprise Test Preparation

## Business challenge
Each company-code UAT setup required coordinated creation and configuration of Jira/Xray Test Plans, Test Executions, execution due dates, Jira filters and nine workstream-specific dashboards. Manual setup typically took approximately **2–3 hours** and introduced repetitive administration across parallel rollout activities.

## My role
Designed and implemented the automation approach for repeatable UAT setup, combining enterprise test-management governance with hands-on Python development.

## Solution
- Used **Python and Jira REST APIs** to automate repeatable test-management configuration.
- Used **Playwright** for interface-driven steps not covered by the API workflow.
- Standardized Test Plans, Test Executions, due-date configuration, filters and dashboard creation.
- Supported workstream leads with additional progress-tracking dashboards.

## Measured outcome
- **Before:** approximately 2–3 hours per UAT setup.
- **After:** approximately 30 minutes.
- **Estimated setup-time reduction:** 75–83%, or 1.5–2.5 hours saved per setup.
- **Broader contribution:** 200+ dashboards created through automation, including additional workstream lead views.

## Business value
Reduced repetitive setup effort, improved consistency across company-code rollouts and made test-execution progress easier for stakeholders to monitor.

## Tools
Python · Jira REST APIs · Jira/Xray · Playwright · JQL · Dashboard automation

> Publication note: Figures are approximate, based on the portfolio owner's reported experience. Avoid implying that all 200+ dashboards were generated in a single UAT setup.
